## YouTube Video & Playlist Length Calculator

A basic YouTube length calculator that calculates the total duration of multiple YouTube videos and playlists.

### Features

* Calculate the total length of multiple YouTube videos and playlists combined
* See the total watch time at different playback speeds:

  * 1.25×
  * 1.5×
  * 1.75×
  * 2×
* Simple and beginner-friendly interface

This is one of my beginner JavaScript projects, built to practice working with JavaScript, APIs, and user input.
